Project Palantír exists to use software engineering and empirical analysis to explore strategy in the Middle-earth Strategy Battle Game.

The goal is not to replace player judgement, but to provide objective evidence that can inform tactical and army-building decisions. Every calculation should be reproducible, every assumption documented, and every result explainable.

Engine Before Interface

Project Palantír prioritises the development of a robust analytical engine before investing in user interface design.

The long-term goal is to ensure that any future interface—command line, desktop, or web—acts as a presentation layer over a mature and well-tested analytical engine.

This philosophy keeps business logic independent from user interaction and improves maintainability.

# Mission Statement

Project Palantír is not intended to replace existing MESBG army builders. Its purpose is to analyse, compare, and explain armies, helping players make better tactical and strategic decisions. Army construction exists only as a means of supplying data to the analysis engine.
